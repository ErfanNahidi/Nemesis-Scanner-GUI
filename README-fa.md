# رابط گرافیکی Nemesis Scanner

Nemesis Scanner یک برنامهٔ دسکتاپ برای ارزیابی یک میزبان در هر بار اجراست. برنامه با Nmap پورت‌ها
و سرویس‌ها را شناسایی می‌کند، یافته‌ها را با داده‌های آسیب‌پذیری محلی یا آنلاین تطبیق می‌دهد و
نتیجهٔ هر اسکن کامل‌شده را به‌شکل گزارش JSON ذخیره می‌کند.

نسخهٔ رابط گرافیکی **1.1.0** است؛ شمارهٔ نسخهٔ موتور اسکن مستقل از نسخهٔ GUI است.

## دریافت و نصب

فایل متناسب با سیستم‌عامل را از [صفحهٔ Releases در گیت‌هاب](https://github.com/ErfanNahidi/Nemesis-Scanner-GUI/releases)
دریافت کنید.

| سیستم‌عامل | فایل | نصب یا اجرا |
| --- | --- | --- |
| Windows x64 | `NemesisScanner.exe` | فایل را دانلود و باز کنید. برای اسکن، Nmap ویندوز را جداگانه نصب کنید. |
| Fedora-compatible Linux x86_64 | `nemesis-scanner-gui-1.1.0-1.x86_64.rpm` | با Software باز کنید یا `sudo dnf install ./nemesis-scanner-gui-1.1.0-1.x86_64.rpm` را اجرا کنید. |
| Debian یا Ubuntu | `nemesis-scanner-gui_1.1.0_all.deb` | با نصب‌کنندهٔ بسته باز کنید یا `sudo apt install ./nemesis-scanner-gui_1.1.0_all.deb` را اجرا کنید. |
| Arch Linux | `nemesis-scanner-gui-1.1.0-1-any.pkg.tar.zst` | `sudo pacman -U ./nemesis-scanner-gui-1.1.0-1-any.pkg.tar.zst` را اجرا کنید. |
| Linux قابل‌حمل x86_64 | `NemesisScanner-1.1.0-x86_64.AppImage` | مجوز اجرا بدهید و فایل را باز کنید. Nmap باید روی سیستم نصب باشد. |

بسته‌های DEB و Arch از Python و کتابخانه‌های همان توزیع استفاده می‌کنند؛ مدیر بسته وابستگی‌های
اعلام‌شده را نصب می‌کند. فایل Windows، Python و کتابخانه‌های برنامه را همراه دارد. Nmap یک برنامهٔ
سیستمی جداگانه است و برای اسکن در همهٔ سیستم‌عامل‌ها لازم است.

## اجرای برنامه از سورس

Python نسخهٔ 3.10 یا جدیدتر، Tkinter، Nmap و نیازمندی‌های Python را نصب کنید و در پوشهٔ `GUI` اجرا
کنید:

```bash
python -m pip install -r requirements.txt
python main.py
```

در Debian و Ubuntu ممکن است Tkinter با بستهٔ `python3-tk` نصب شود؛ در Fedora معمولاً بستهٔ
`python3-tkinter` آن را فراهم می‌کند. برنامه را با همان محیط Python که نیازمندی‌ها را در آن نصب
کردید اجرا کنید. برنامهٔ سورس را با `sudo python main.py` اجرا نکنید.

## اجرای نخستین اسکن

1. صفحهٔ **Network scan** را باز کنید.
2. یک نشانی IPv4، نشانی IPv6 یا نام میزبان وارد کنید.
3. یکی از پروفایل‌های **Quick**، **Common** یا **Full TCP** را انتخاب کنید.
4. در صورت نیاز اسکریپت‌های آسیب‌پذیری Nmap، بررسی فعال سرویس و منبع داده را انتخاب کنید. در لینوکس،
   اگر نوع اسکن به دسترسی خام شبکه نیاز دارد، گزینهٔ **Request administrator access for Nmap** را
   فعال کنید تا پنجرهٔ احراز هویت دسکتاپ برای Nmap باز شود.
5. مجوز ارزیابی میزبان را تأیید کنید و **Run scan** را بزنید.
6. سرویس‌های شناسایی‌شده و یافته‌ها را ببینید. گزارش کامل‌شده در **Scan reports** و داشبورد نمایش
   داده می‌شود.

فقط سامانه‌هایی را اسکن کنید که مالک آن هستید یا اجازهٔ روشن برای ارزیابی آن‌ها دارید. راهنمای
کامل در [MANUAL.md](MANUAL.md) است.

## ساخت بسته‌ها

برای ساخت RPM و AppImage روی Fedora x86_64، PyInstaller، `rpmbuild` و `appimagetool` را نصب و
`./build-linux.sh` را اجرا کنید. برای DEB و بستهٔ Arch دستور `./build-deb-arch.sh` را روی سیستمی
با `dpkg-deb`، `tar` و `zstd` اجرا کنید. برای ساخت EXE در Windows، فایل `build-windows.ps1` را اجرا
کنید. خروجی‌ها در `dist/` قرار می‌گیرند و در Git ثبت نمی‌شوند.

## داده و حریم خصوصی

گزارش‌ها، فهرست میزبان‌های اخیر و حافظهٔ نهان دادهٔ آنلاین در پوشهٔ دادهٔ کاربر ذخیره می‌شوند:

- Linux: `~/.local/share/nemesis-scanner/` یا مسیر تعیین‌شده با `$XDG_DATA_HOME`
- Windows: پوشهٔ `.local/share/nemesis-scanner` در پوشهٔ کاربر، مگر اینکه `XDG_DATA_HOME` تنظیم شده
  باشد.

گزارش شامل میزبان هدف، سرویس‌های شناسایی‌شده، زمان اسکن و یافته‌های آسیب‌پذیری است. کلیدهای API در
رابط پوشیده‌اند و فقط برای اسکن جاری به‌کار می‌روند؛ داخل گزارش یا تنظیمات برنامه ذخیره نمی‌شوند.
متغیرهای `NVD_API_KEY` و `VULNERS_API_KEY` می‌توانند فیلد کلیدها را از پیش پر کنند.

در بررسی آنلاین، اطلاعات محصول و سرویس برای جست‌وجو به NVD و در صورت انتخاب، به Vulners ارسال
می‌شود. گزینهٔ پایگاه محلی به این سرویس‌ها نیاز ندارد. خود اسکن شبکه همچنان با Nmap و مستقیماً روی
میزبان هدف انجام می‌شود.
